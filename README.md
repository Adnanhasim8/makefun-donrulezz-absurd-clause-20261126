# The Absurd Clause — left-sock license

One absurd clause buried deep inside a terms-of-service agreement: deadpan
legal boilerplate ("non-exclusive license … in perpetuity, worldwide") that
quietly turns absurd — the license covers your left sock, and nobody explains
why. Entry for the make.fun Absurd Clause Contest
(`u-donrulezz-the-absurd-clause-contest-035cc0f1`).

## How to run

```sh
python3 main.py
```

Writes the single-line entry (95 characters) to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set).
Python 3.13 standard library only; no network at run time.
